개인정보처리방침

이 방침은 개인용 Gmail 도우미 Alfred-Gmail의 데이터 처리 방식을 설명합니다.

1. 접근하는 정보와 목적

소유자가 승인한 Gmail 계정의 주소, 메일 헤더(발신자·수신자·제목·일시), 본문, 라벨 등 Gmail 읽기 전용 API로 조회 가능한 정보를 필요한 범위에서 사용합니다. 목적은 소유자가 요청한 메일 검색·열람·요약입니다.

2. OAuth 인증 정보

계정별 OAuth 토큰과 앱 인증 정보는 소유자가 관리하는 서버의 별도 파일에 보관하며 파일 접근 권한을 제한합니다. Google 로그인 비밀번호는 보관하지 않습니다. 토큰과 메일은 이 공개 사이트 또는 공개 GitHub 저장소에 게시하지 않습니다.

3. AI 처리 및 외부 서비스

요약·질의 처리를 요청하면 필요한 메일 내용이 설정된 AI 모델 제공자에게 전송될 수 있습니다. 결과와 대화는 사용 중인 채팅 서비스 및 에이전트의 기록에 남을 수 있습니다. 해당 제공자의 보관·처리 조건이 적용되며, 이 앱은 외부 서비스의 무보관이나 학습 제외를 일괄 보장하지 않습니다. 민감한 메일은 처리 전에 제공자 설정을 검토해야 합니다.

운영자는 Gmail 정보를 판매하거나 광고 타기팅에 사용하지 않으며, 일반 목적 AI 모델 학습용 데이터셋을 만들기 위해 수집하지 않습니다.

4. 보관과 삭제

토큰은 연결 유지에 필요한 동안 보관합니다. 조회 결과, 대화 기록 및 로그의 보관 기간은 서버와 이용 서비스의 설정에 따르며 자동 삭제를 보장하지 않습니다. 소유자는 서버의 토큰·기록을 삭제하고, 외부 서비스에 남은 기록도 해당 서비스에서 별도로 삭제할 수 있습니다.

5. 권한 철회

Google 계정의 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 권한 철회는 기존 대화 기록이나 외부 서비스에 저장된 결과까지 자동으로 삭제하지는 않습니다.

6. 안내 사이트 방문

이 정적 사이트에는 앱 자체의 분석 스크립트, 로그인 폼 또는 추적 쿠키를 추가하지 않습니다. 호스팅 제공자인 GitHub는 서비스 제공을 위해 접속 정보 등을 자체 방침에 따라 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요.

7. 문의 및 변경

GitHub 문의 (공개 게시판이므로 메일 내용, 이메일 주소, 인증 정보 등 개인정보를 게시하지 마세요.)

운영 방식이 변경되면 이 페이지를 수정합니다. 이 방침은 개인용 앱 운영 안내이며 Google의 앱 검증 통과를 의미하지 않습니다.
